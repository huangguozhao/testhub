## 五、代码规范

### 5.1 模块命名

```
com.testhub.modules.{module}
├── domain/          # 实体类
├── mapper/         # MyBatis Mapper
├── service/        # 服务接口
│   └── impl/       # 服务实现
├── controller/     # 控制器
└── dto/           # 数据传输对象
```

### 5.2 包命名

| 类型 | 后缀 | 示例 |
|------|------|------|
| 实体 | Entity | UserEntity |
| DTO | DTO | LoginDTO |
| VO | VO | UserVO |
| Mapper | Mapper | UserMapper |
| Service | Service | AuthService |
| Controller | Controller | AuthController |

### 5.3 数据库命名

| 类型 | 规范 | 示例 |
|------|------|------|
| 表名 | 小写下划线 | sys_user |
| 字段名 | 小写下划线 | created_at |
| 外键 | {table}_id | user_id |
| 索引 | idx_{table}_{field} | idx_user_username |
