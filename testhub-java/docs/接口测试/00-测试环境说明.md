## 四、快速开始

### 4.1 启动服务

```bash

cd D:\Project\testhub_platform\testhub-java
mvn spring-boot:run

# 或使用 jar 包
java -jar target/testhub-java.jar
```


## 七、Postman 使用说明

### 7.1 导入 Collection

1. 打开 Postman
2. 点击 Import
3. 选择 `postman/xxx.postman_collection.json` 文件
4. 导入成功

### 6.2 配置 Environment

1. 新建 Environment，命名为 `TestHub Dev`
2. 添加变量：
   - `baseUrl`: http://127.0.0.1:8080/api
   - `accessToken`: (留空，登录后自动填充)
3. 在 Collection 的 Auth 中设置：
   - Type: Bearer Token
   - Token: {{accessToken}}

### 6.3 运行测试

1. 先运行登录请求获取 Token
2. 使用 Tests 脚本自动保存 Token 到环境变量
3. 运行其他测试用例

## 七、常见问题

### 7.1 Token 过期

Access Token 有效期 15 分钟，过期后需要刷新：

```bash
curl -X POST http://127.0.0.1:8080/api/auth/refresh \
  -H "Content-Type: application/json" \
  -d '{"refreshToken": "your_refresh_token"}'
```

### 7.2 401 Unauthorized

检查：
1. Token 是否正确设置
2. Token 是否过期
3. 请求头格式是否正确：`Authorization: Bearer <token>`

### 7.3 服务无法启动

检查：
1. 端口 8080 是否被占用
2. 数据库连接是否正常
3. Redis 连接是否正常

### 7.4 数据库表不存在

执行数据库初始化脚本：

```bash
mysql -u root -p testhub < sql/init_database.sql
```
